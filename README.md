# Heip
Мужчина ведёт девушку за руку по оживлённой улице. Девушка испуганно смотрит на прохожих, незаметно показывает жест о помощи и передаёт одному из них записку с надписью «HELP ME». Прохожий понимает сигнал. Реалистичная мимика, скрытое напряжение, кинематографичная камера, вертикальное видео 9:16.
